Command Line Interface

Press Alt + C to open the terminal overlay.

  • focus [mins] Start flow timer
  • rain [0-100] Set rain volume
  • lofi [0-100]Set lofi radio volume
  • theme [light/dark/crt]Change the UI theme
  • font [sans/mono/serif/typewriter]Change system typography
  • zenToggle focus mode
  • glassToggle glass effect
  • strictToggle strict mode in timer
  • clear scratchpad clear the notes
  • todo [task]Add a task to Focus list
  • note [text]Append text to scratchpad
  • local [play/next/prev]Control local players
